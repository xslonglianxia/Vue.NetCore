# 05. 关键模块与类参考

> 本节是**开发查询手册**：按"模块 → 类 → 方法"层级逐项说明，方便二次开发定位。

## 5.1 后端核心基类（VOL.Core/BaseProvider）

### 5.1.1 ServiceBase&lt;TEntity, TRepository&gt;

路径：`VOL.Core/BaseProvider/ServiceBase.cs`

主要方法：

| 方法 | 签名 | 说明 |
|------|------|------|
| `GetPageData` | `PageGridData<T> GetPageData(PageDataOptions options)` | 分页查询（同步） |
| `GetPageDataAsync` | `Task<PageGridData<T>> GetPageDataAsync(PageDataOptions options)` | 分页查询（异步） |
| `GetDetailPage` | `object GetDetailPage(PageDataOptions pageData)` | 主从表详情 |
| `GetDetailPageAsync` | `Task<object> GetDetailPageAsync(PageDataOptions pageData)` | 异步主从表详情 |
| `Add` | `WebResponseContent Add(SaveModel saveModel)` | 新增（含校验、审计字段填充） |
| `Update` | `WebResponseContent Update(SaveModel saveModel)` | 更新 |
| `Del` | `WebResponseContent Del(params object[] keys)` | 删除（支持逻辑删除） |
| `Import` | `WebResponseContent Import(...)` | Excel 导入 |
| `Export` | `WebResponseContent Export(PageDataOptions options)` | Excel 导出 |
| `Upload` | `WebResponseContent Upload(IFormFile file)` | 上传 |
| `SaveAudit` | `WebResponseContent SaveAudit(SaveModel sm)` | 审批流保存 |
| `FindAsIQueryable` | `IQueryable<T> FindAsIQueryable(Expression<Func<T,bool>>, bool filterDeleted=true)` | 暴露给业务的 IQueryable |
| `CacheContext` | `ICacheService` 属性 | 缓存服务 |

业务侧常用扩展回调（在 `ApplicationServiceBase` 中定义）：

| 回调 | 触发时机 |
|------|----------|
| `AddOnExecuting(T, object, ...)` | 新增保存数据库前，可改数据 |
| `AddOnExecuted(...)` | 新增后 |
| `UpdateOnExecuting` / `UpdateOnExecuted` | 更新 |
| `DelOnExecuting` / `DelOnExecuted` | 删除 |
| `ImportOnExecuting` / `ImportOnExecuted` | 导入 |
| `ExportOnExecuting` / `ExportOnExecuted` | 导出 |
| `GetPageDataOnExecuted` / `GetPageDataOnExecutedAsync` | 分页查询结果集二次处理 |
| `GetDetailPageOnExecuted` / `GetDetailPageOnExecutedAsync` | 主从表详情二次处理 |
| `SummaryExpress` / `SummaryExpressAsync` | 合计行表达式 |
| `OrderByExpression` | 自定义排序 |
| `QueryRelativeExpression` | 追加查询条件 |
| `QueryRelativeList` | 追加字符串条件 |
| `QuerySql` | 原生 SQL 覆盖查询 |

### 5.1.2 RepositoryBase&lt;TEntity&gt;

路径：`VOL.Core/BaseProvider/RepositoryBase.cs`

| 属性/方法 | 说明 |
|------|------|
| `DbContext` | EFCore `BaseDbContext`（在 SqlSugar 版中是 `ISqlSugarClient`） |
| `DapperContext` | `ISqlDapper` Dapper 入口 |
| `DBSet` | EFCore `DbSet<T>` |
| `DbContextBeginTransaction(Func<WebResponseContent>)` | 事务封装 |
| `DbContextBeginTransactionAsync(...)` | 异步事务 |
| `FindAsIQueryable` | IQueryable 查询 |
| `ExecuteSqlCommand` / `ExecuteSqlQuery` | 原生 SQL 能力 |

> SqlSugar 版 `RepositoryBase` 内部使用 `ISqlSugarClient.Queryable<T>()`，提供同等能力。
