## 6.7 跨域配置

`appsettings.json#CorsUrls`：
```
"http://127.0.0.1:9990,http://localhost:9990,http://www.volcore.xyz"
```

`Program.cs` 中：
```csharp
options.AddPolicy("cors", builder =>
    builder.SetIsOriginAllowed(_ => true)
           .AllowAnyMethod()
           .AllowAnyHeader()
           .AllowCredentials());
```

> 生产环境请收敛到具体域名，**不要使用 `AllowAnyOrigin()`**。

## 6.9 安全建议

1. **修改默认 JWT/Secret/User/DB/Redis 密钥**（`appsettings.json#Secret`）。
2. **修改 `QuartzAccessKey`**。
3. **修改默认管理员密码 `admin666 / 123456`**。
4. **生产环境关闭 Swagger**：
   ```csharp
   // 注释或判断 env.IsDevelopment()
   app.UseSwagger();
   app.UseSwaggerUI();
   ```
5. **生产环境使用具体 CORS 域名**。
6. **数据库连接字符串加密**（框架自带加密工具）。
7. **启用国密 SM2/SM3/SM4**（信创场景）。
