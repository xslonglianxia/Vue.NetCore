# 07. 数据库与脚本

> 数据库初始化脚本位于仓库根目录的 `DB/` 下，按数据库类型分目录存放。

## 7.1 目录概览

```
DB/
├── DM/                ── 达梦数据库
│   └── DM.sql
├── Oracle/            ── Oracle
│   ├── NETCOREDEV.sql
│   └── 自增序列.sql
├── mysql/             ── MySQL
│   ├── mysql批量日志写入失败.txt   ← 已知问题说明
│   └── mysql表结构与表数据.sql
├── pgsql/             ── PostgreSQL
│   ├── (必看)pgsql使用说明.doc
│   └── pgsql.sql
```

> ⚠️ **建议先阅读**：
> - `Oracle数据库必看.txt`（仓库根）
> - `pgsql/(必看)pgsql使用说明.doc`
> - `mysql/mysql批量日志写入失败.txt`

## 7.2 各数据库使用要点

### 7.2.1 SQL Server（推荐首选）

- 默认库名：`vol_v3`
- 执行：`DB/sqlserver/表结构与数据.sql` 即可
- 配套 `appsettings.json`：
  ```json
  "Connection": {
    "DBType": "MsSql",
    "UseSqlserver2008": "0",
    "DbConnectionString": "Data Source=.\\SQLEXPRESS;Initial Catalog=vol_v3;...;TrustServerCertificate=True"
  }
  ```
- SqlServer 2008 需要 `UseSqlserver2008=1`，并安装 `EntityFrameworkCore.UseRowNumberForPaging`（框架已包含）。

### 7.2.2 MySQL

- 执行 `DB/mysql/mysql表结构与表数据.sql`
- 配套配置：
  ```json
  "DBType": "MySql",
  "DbConnectionString": "Data Source=127.0.0.1;Database=vol_v3;AllowLoadLocalInfile=true;User ID=root;Password=123456;allowPublicKeyRetrieval=true;pooling=true;CharSet=utf8;port=3306;sslmode=none;"
  ```
- ⚠️ **批量日志写入失败**：`mysql/mysql批量日志写入失败.txt` 中说明 MySQL 在大批量 INSERT 时需要注意参数 `AllowLoadLocalInfile=true`，且 EFCore 8 默认批量大小限制。

### 7.2.3 PostgreSQL

- 执行 `DB/pgsql/pgsql.sql`，并阅读 `pgsql使用说明.doc`
- 配置：
  ```json
  "DBType": "PgSql",
  "DbConnectionString": "Host=127.0.0.1;Port=5432;User id=postgres;password=xxxx;Database=vol_v3;"
  ```
- PG 中 Guid 字段映射为 `uuid`、布尔为 `boolean`，框架已处理。

### 7.2.4 Oracle

- 执行 `DB/Oracle/NETCOREDEV.sql` + `自增序列.sql`（Oracle 需要序列自增）
- 配套 `appsettings.json`：
  ```json
  "DBType": "Oracle",
  "DbConnectionString": "user id=C##NETCOREDEV;data source=127.0.0.1/ORCL;password=123456;"
  ```
- ⚠️ 阅读 `Oracle数据库必看.txt`（根目录）注意表空间/账号。

### 7.2.5 达梦（DM）

- 执行 `DB/DM/DM.sql`
- 配置：
  ```json
  "DBType": "DM",
  "DbConnectionString": "Server=127.0.0.1:5236; schema=netcoredev; User=SYSDBA; Password=SYSDBA;"
  ```
- 框架使用 `DM.Microsoft.EntityFrameworkCore`（EFCore 版）或 SqlSugar 内置 DM 适配（SqlSugar 版）。

## 7.3 数据库通用表约定

所有业务表**强烈建议**包含以下审计字段（`CreateMember` / `ModifyMember` 默认配置）：

| 字段 | 类型 | 含义 |
|------|------|------|
| `CreateID` | int | 创建人 ID |
| `Creator` | nvarchar(30~50) | 创建人名 |
| `CreateDate` | datetime | 创建时间 |
| `ModifyID` | int | 修改人 ID |
| `Modifier` | nvarchar(30~50) | 修改人名 |
| `ModifyDate` | datetime | 修改时间 |

> `ServiceBase.Add` / `Update` 会**自动**给这些字段赋值（基于 `appsettings.json#CreateMember` / `ModifyMember` 配置），无需业务代码手工 set。
> 也可以在实体中通过 `T.SetCreateDefaultVal()` / `T.SetModifyDefaultVal()` 手动调用。

## 7.4 字段类型映射（不同数据库）

| C# 类型 | SQL Server | MySQL | PostgreSQL | Oracle | DM |
|------|----|----|----|----|----|
| `int` | int | int | integer | NUMBER(10) | INT |
| `long` | bigint | bigint | bigint | NUMBER(19) | BIGINT |
| `string` | nvarchar | varchar | varchar | NVARCHAR2 | VARCHAR |
| `DateTime` | datetime | datetime | timestamp | DATE / TIMESTAMP | TIMESTAMP |
| `bool` | bit | tinyint(1) | boolean | NUMBER(1) | BIT |
| `decimal` | decimal(p,s) | decimal(p,s) | decimal(p,s) | NUMBER(p,s) | DECIMAL(p,s) |
| `Guid` | uniqueidentifier | char(36) | uuid | CHAR(36) | CHAR(36) |
| `byte[]` | varbinary | longblob | bytea | BLOB | BLOB |

> Dapper 的 Guid 解析在每种数据库下都有对应 `DapperParseGuidTypeHandler*`，框架已自动注册。

## 7.5 主键策略

- 默认：**雪花 ID（long）** 或 **Guid** 两种风格
- 雪花 ID：开启 `EnableSnowFlakeID=true`，配合 `SnowFlakeOptions`
- Guid：实体主键为 `Guid`，SqlServer 默认为 `uniqueidentifier`，其他库为 `char(36)`
- 数据库自增：业务可自由选择，框架不强约束

## 7.6 多租户字段约定

启用多租户时（`IsMultiTenancy = true`），需在业务表中增加 `TenantId` 字段（int 或 long），`TenancyManager` 会自动注入过滤条件。

## 7.7 表名与字段名约定

- **表名**：使用 PascalCase，如 `MES_Bom_Main`、`Sys_User`
- **字段名**：使用 PascalCase
- **前缀**：
  - `Sys_` — 系统表
  - `MES_` — 演示 MES 业务表
  - 业务方自定义前缀（建议 3 字母大写 + 下划线）

## 7.8 数据初始化顺序

1. 创建数据库 `vol_v3`（或自定义名）
2. 执行对应数据库的 `*.sql`（含表结构 + 种子数据）
3. 修改 `appsettings.json#Connection.DbConnectionString`
4. 启动后端，确认 Swagger 能看到 `Sys_User` 等表
5. 启动前端，使用 `admin / 123456` 或 `admin666 / 123456` 登录

## 7.9 迁移与升级

- 框架 3.x → 4.x：使用 `EFCore Migrations`（EFCore 版），具体步骤见 `2.现有项目升级.doc` / `3.ef后台升级.net8.0.docx` / `4.sugar后台升级net8.0.docx`
- 自定义业务表：使用代码生成器反向生成实体到 `VOL.Entity/DomainModels/`，再生成 Repository/Service
- 二开表：建表 → 在 `Sys_Menu` 注册菜单 → 在代码生成器中选择该表 → 一键生成
