## 项目一句话总结

> 只需要在数据库建表 → 通过代码生成器一键生成 **Controller / Service / Repository / Entity / Vue 页面** → 直接得到可运行的主从表 CRUD、导入导出、审批流、低代码表单。

提供近 300 个前后端扩展点，默认支持**MySQL / SQLServer / PostgreSQL / Oracle / 达梦**，并提供基于 **EFCore** 和 **SqlSugar** 的两个并行后端实现。

## 核心特性速览

- **代码生成器**：可视化生成前后端代码，30+ 配置项，支持主从表、一对多从表。
- **多数据库适配**：同一份代码支持 5 种主流数据库（含国产达梦）。
- **双 ORM 实现**：EFCore 版本（生产稳定）+ SqlSugar 版本（高性能、可二开）。
- **低代码表单设计器**：通过拖拽即可生成业务表单与审批流。
- **工作流引擎**：内置图形化审批流配置，支持会签、驳回、撤回。
- **权限系统**：基于 `Sys_Menu / Sys_Role / Sys_User` 的菜单 + 数据权限模型。
- **国密算法**：默认开启 SM2/SM3/SM4 信创支持。
- **多端支持**：Web (Vue3)、uniapp (App/H5/小程序) 共享同一套后端 API。
